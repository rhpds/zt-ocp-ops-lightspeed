= OpenShift Lightspeed Lab
:page-toclevels: 1

Use OpenShift Lightspeed, the AI assistant in the OpenShift web console, to explore OpenShift concepts, generate YAML, and troubleshoot a workload.

**Duration:** 20-30 minutes, including setup and cleanup +
**Audience:** Platform engineers, developers, and operations teams +
**Prerequisites:** A provisioned OpenShift cluster with administrator access, the OpenShift Lightspeed Operator, and LLM provider credentials.

== Your Lab Workspace

The instructions appear on the left. Use the tabs on the right to work with your cluster, and drag the divider to resize the panels.

[cols="1,3",options="header"]
|===
|Tab |Purpose

|**OCP Console**
|Open the OpenShift web console and use the Lightspeed chat assistant.

|**Terminal**
|Run the lab's `oc` commands in the supplied browser terminal.

|**Terminal 2**
|Keep a second terminal available to monitor pods while running commands in the first.
|===

TIP: Use the execute button on command blocks to send commands to the primary **Terminal** tab. Run monitoring commands manually in **Terminal 2** so the primary terminal remains available.

== Verify Terminal Access

Open **Terminal** and check that the OpenShift CLI is authenticated:

[source,bash,role="execute"]
----
oc whoami
oc whoami --show-server
oc get nodes
----

Confirm that the user and API server belong to your lab environment and that the nodes show `Ready`. The number of nodes depends on your environment.

If `oc whoami` reports that you are not logged in, open the user menu in the console, select **Copy login command**, and follow the prompts. Paste the supplied `oc login` command into **Terminal**, then repeat the checks above. Verify `oc whoami` in **Terminal 2** as well before using it.

== Lab Prerequisites

Your environment must already have:

* The OpenShift Lightspeed Operator installed in `openshift-lightspeed`.
* An `azure-api-keys` secret in that namespace containing the supplied Azure OpenAI credentials.
* Access to the Azure OpenAI endpoint configured for the lab.

The exercise verifies these prerequisites, creates the `OLSConfig`, and deploys a demo pod in `lightspeed-demo` for troubleshooting. Contact your lab provider if the operator or credentials secret is missing.
